ปรับปรุงล่าสุด 28 ตุลาคม 2569

สรุปสั้น ๆ

krisscode.dev เป็นเว็บไซต์ส่วนตัวแบบ static ไม่มีระบบสมาชิก ไม่มีฐานข้อมูล และไม่ได้ใช้เครื่องมือวิเคราะห์ผู้เข้าชมหรือโฆษณา

ฟอร์มติดต่อ

ข้อมูลที่คุณกรอกในฟอร์มจะไม่ถูกส่งมาที่เซิร์ฟเวอร์ของเว็บนี้ เมื่อกดส่ง เบราว์เซอร์จะเปิดโปรแกรมอีเมลของคุณพร้อมข้อความที่กรอกไว้ และอีเมลจะถูกส่งก็ต่อเมื่อคุณกดส่งในโปรแกรมอีเมลเอง

ข้อมูลที่เก็บในเบราว์เซอร์ของคุณ

เว็บนี้บันทึกเฉพาะธีมที่คุณเลือก (สว่างหรือมืด) ไว้ใน localStorage ของเบราว์เซอร์ ข้อมูลนี้อยู่ในเครื่องของคุณเท่านั้น และลบได้ด้วยการล้างข้อมูลเว็บไซต์ในเบราว์เซอร์

บริการภายนอกที่เว็บนี้ใช้

  • GitHub Pages โฮสต์ไฟล์ของเว็บไซต์
  • Cloudflare ให้บริการ DNS เครือข่ายส่งไฟล์ และระบบความปลอดภัย ซึ่งอาจตั้งคุกกี้ที่จำเป็นด้านความปลอดภัย
  • Google Fonts และ jsDelivr ส่งไฟล์ฟอนต์และไอคอนให้เบราว์เซอร์ของคุณ

ผู้ให้บริการเหล่านี้จะเห็นที่อยู่ IP และข้อมูลทางเทคนิคของคำขอ เช่น ประเภทเบราว์เซอร์ ตามนโยบายความเป็นส่วนตัวของแต่ละราย
